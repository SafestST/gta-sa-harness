## Role
The **mission script** — the game's own executable program layer. 3,079,599 B.
Contains all mission threads, side-missions, custom-script machinery and the
game's logic loop. Loaded/interpreted by `CTheScripts` (the SCM VM in the
engine). `data\main.sc` (G-0074) is the secondary/script entry companion.

## Structure (observed)
- Header bytes: `02 00 01 20 AB 00 00 73 ...` (first 8 bytes)
  - 4-byte SCM version marker + header fields (variable counts etc.)
  - exact header field semantics [UNVERIFIED] — confirm vs SCM spec
- Body: compiled opcode stream (LE 32-bit opcodes), string table, global/local
  variable sections, jump-table entries for mission starts.
- Sizes: mission variables, custom script count, etc. derivable from header
  offsets once confirmed.
