# G-0072
domain: game | type: text-config | path: data\handling.cfg
format: handling-cfg | depth: P0 (fully readable text)

## Role
The vehicle physics definition table. One record per vehicle/vehicle variant
defining mass, engine, grip, suspension, drag, gearbox and more. Consumed by
`CGame::cHandlingDataMgr` at startup to instantiate every drivable vehicle's
dynamics. 516 lines; header comments document units and are authored by
"Bill Henderson" (Rockstar).

## Structure
- `;` = comment lines (units + field guide)
- One block per vehicle: `HANDLING <vehicleId> <field> ...`
  - `; <id>` comment lines precede each block, naming the vehicle (e.g. LANDSTAL)
  - fields ordered per the documented units: mass (kg), dimensions (m),
    acceleration/deceleration (ms^-2), multipliers (x1.0 default), angles (deg)

## Relations
- B-G05 VEHICLE SYSTEM: paired with `vehicles.ide` (id->model mapping),
  `carcols.dat` (colours), `carmods.dat` (mods), `cargrp.dat` (traffic groups)
- Model refs inside cross-link to DFF/TXD in `models\gta3.img` (G-0339)
