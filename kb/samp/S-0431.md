# S-0431
domain: samp | type: world-data | path: SAMP\SAMP.ide
format: ide | depth: P0 (fully readable text)

## Role
The **SAMP item-definition table** — 2,069 lines. Registers the custom model
ids used by the SAMP world overlay. Header credits: "cessil, Kalcor, Matite and
Micky (September 2010 to April 2015)" and references the SA-MP 0.3.7 wiki
(http://wiki.sa-mp.com). Includes documented IMG fixes (elevator COL brightness
ID:18755, AnimTube grating ID:19901, draw-distance tweaks 19475-19483).

## Structure
- `#` = comment lines (file provenance + per-edit notes)
- `objs` / `tobj` sections: `<id> <modelname> <txdname> <drawdist> <flags>`
- Links model ids to DFF/TXD names served from SAMP.img (S-0432)

## Relations
- B-S02 SAMP WORLD OVERLAY with SAMP.ipl (S-0433), SAMP.img (S-0432),
  samaps.txd (S-0430); CUSTOM.ide (S-0428) = user layer
- Same format/grammar as game *.ide (see kb/01_TAXONOMY.md) — identical reader

## Annotations
- SAMP.ide ids are used by server scripts (SetObjectModel etc.) — the id
  registry here is the canonical "SAMP object catalogue".
- This is P0: a full Phase 2 read yields the complete SAMP object model list.
