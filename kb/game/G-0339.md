# G-0339
domain: game | type: archive-img | path: models\gta3.img
format: img | depth: P1 (container structural)

## Role
The **main world model archive** — 940 MB, the single largest entity. Contains
the DFF (geometry), TXD (texture) and COL (collision) entries that build the
entire GTA San Andreas world and every base model/vehicle/ped.

## Structure
- Directory-based archive (IMG "dir2" style): header with entry count + offset,
  then a directory table of (offset, size, name) records pointing at raw
  RenderWare binary sections (DFF/TXD/COL).
- Entries are named; the names cross-link to `*.ide` model names and `*.ipl`
  placements. The directory can be listed (entry names + offsets + sizes)
  without decoding the sections.
- Inner DFF/TXD/COL binary anatomy documented in kb/01_TAXONOMY.md (P1).

## Relations
- B-G01 WORLD MODEL ARCHIVE: paired with data\maps\**\.ide|.ipl (LA/SF/vegas/
  country/interior), loaded per gta.dat order (G-0070)
- Sibling archives: gta_int.img (interiors), player.img, cutscene.img,
  data\script\script.img

## Annotations
- SAMP reuses this pipeline via its own IMGs (S-0432 SAMP.img, S-0434
  SAMPCOL.img) — same format, separate archives.
- Listing the entry table is a cheap, high-value Phase 2 task (name -> what
  the world references).
