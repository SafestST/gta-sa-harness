domain: samp | type: archive-img | path: SAMP\SAMP.img

## Role
The **SAMP world model archive** — 47,236,096 B. Holds the DFF/TXD entries
behind every model id registered in SAMP.ide (S-0431). Same IMG dir2 format as
the game's gta3.img (G-0339) — SAMP reuses the engine's streaming pipeline
verbatim rather than a private format.

## Structure
- Standard IMG directory: entry table (name, offset, size) -> raw RenderWare
  sections (DFF/TXD). Listing the entry table = the SAMP model inventory.

## Relations
- B-S02 SAMP WORLD OVERLAY: SAMP.ide (S-0431) names them, SAMP.ipl (S-0433)
  places them, SAMPCOL.img (S-0434) collides them, samaps.txd (S-0430) textures
- User layer: custom.img (S-0429) + CUSTOM.ide (S-0428)

## Annotations
