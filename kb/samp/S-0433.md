# S-0433
domain: samp | type: world-data | path: SAMP\SAMP.ipl
format: ipl | depth: P0 (fully readable text)

## Role
The **SAMP placement / cull table** (2,291 B). Instantiates SAMP's world
objects. Per its header it specifically adds **new cull zones for the
enterable buildings** ("prevent weather from appearing inside them"), authored
by Matite (Jan-Feb 2015).

## Structure
- `#` = comments (provenance)
- `cull` section: `<x1,y1,z1> <x2,y2,z2> <flags>` box zones
- standard `inst` sections reference ids registered in SAMP.ide (S-0431)

## Relations
- B-S02 SAMP WORLD OVERLAY: pairs with SAMP.ide (S-0431) and payload in
  SAMP.img (S-0432); same grammar as game *.ipl
- Cull zones here interact with the game's occlusion system (data\maps\occlu*.ipl)

## Annotations
- Small file: a complete Phase 2 read is trivial and yields every SAMP-added
  cull zone + instanced object.
