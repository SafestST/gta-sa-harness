# G-0070
domain: game | type: text-config | path: data\gta.dat
format: gta-dat | depth: P0 (fully readable text)

## Role
The **master data-loader script** — the spine of the entire data pipeline.
146 lines. Dictates the ORDER in which the engine loads archive, IDE and IPL
files. Header comment: "Load IDEs first, then the models and after that the IPLs".

## Structure
Directive-keyed lines (order matters):
- `IMG <path>` — register an archive for streaming (e.g. DATA\PATHS\CARREC.IMG,
  DATA\SCRIPT\SCRIPT.IMG, MODELS\CUTSCENE.IMG)
- `SPLASH <name>` — loading splash (loadsc2)
- `IDE <path>` — register an item-definition table (e.g. generic\vegepart.IDE,
  generic\barriers.IDE, LA\LAn.IDE ...)
- `IPL <path>` — place items (world instances)
- `TEXDICTION <txd>` / `MODELFILE <dff>` / `HIERFILE` / `COLFILE` etc. as
  encountered (binary section keywords)

## Relations
- B-G11 DATA LOADER; drives B-G01/B-G02/B-G04 loading; only *additional* IMGs
  are listed here (gta3.img / gta_int.img / player.img are engine auto-loads)
- SAMP is NOT referenced here — SAMP self-registers (see kb/samp, B-S01..S03)

## Annotations
- Any change to this file changes load precedence: it is the canonical map of
  "what defines the world, in what order". Do not reorder blindly.
